# 05: 管理员确认后的最新数据处理与自动触发

**What to build:** 管理员确认后，系统重新读取最新选手、队伍和登记数据，幂等地执行对应处理，更新最终状态并通知相关人员；新登记也会被自动发现和处理，已完成、已跳过或待确认的记录不会被重复执行。

**Blocked by:** 04: 管理员冲突通知与登记状态闭环.

**Status:** ready-for-agent

- [ ] 新登记可由自动处理机制发现并进入既定校验与冲突分类流程，无需手动启动导入。
- [ ] 确认动作在处理前重新读取最新数据；同一登记的重复确认不会重复创建、更新或发送成功通知。
- [ ] 成功后登记状态、队伍数据和通知结果一致；处理失败保留可诊断结果且不伪造成功。
