# 01: 组队收集表提交与基础校验闭环

**What to build:** 队长可提交 3–5 人队伍；系统按手机号匹配选手、校验大一与“已验证”资格，并把成功或普通失败的结果写回登记。普通失败仅通知队长，队长没有 `open_id` 时按规则通知首个可用队友；dry-run 不发消息、不写数据。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 覆盖字段完整性、手机号、人数、选手匹配、年级、验证状态和一人一队等资格闸门，并为普通失败保留具体原因。
- [ ] 成功时仅通知队长，普通失败时按队长优先、首个可用队友兜底的规则发送一次结果；无可用收件人时记录原因。
- [ ] 成功、失败、空提交和重复来源均有可验证的登记状态与处理结果，且 dry-run 没有外部副作用。
