# 04: 管理员冲突通知与登记状态闭环

**What to build:** 每个结构性冲突只向配置的管理员发送包含登记 ID、冲突类型、原队伍和新成员的通知；通知失败不会改变待确认状态，而失败原因会写入处理结果。重复扫描不会重复通知或重复处理。

**Blocked by:** 03: 重复、增员与结构性冲突识别.

**Status:** ready-for-agent

- [ ] 管理员通知对象从配置读取，业务逻辑不硬编码管理员身份。
- [ ] 通知内容包含登记记录 ID、冲突类型、原队伍 ID 和成员、以及新提交的队长和成员。
- [ ] 管理员通知失败时保留“需管理员确认”状态并记录失败原因；重复运行不重复发送同一冲突通知。
