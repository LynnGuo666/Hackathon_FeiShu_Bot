# 02: 组队收集表的队友人数条件展示

**What to build:** 表单依队友人数展示对应数量的队友字段，减少无关输入；处理流程仍能可靠地校验实际人数与填写人数一致。飞书表单条件逻辑若只能在编辑界面配置，则明确交付可执行的人工配置步骤与验证结果。

**Blocked by:** 01: 组队收集表提交与基础校验闭环.

**Status:** ready-for-agent

- [ ] 队友人数为 0–4 时，表单只呈现与该人数相符的队友填写入口或明确的受支持替代交互。
- [ ] 提交处理拒绝人数声明与实际队友资料不一致的登记。
- [ ] 验证说明区分 API 可自动配置的内容与必须在飞书表单编辑界面完成的条件逻辑，不将静态隐藏冒充为动态展示。
