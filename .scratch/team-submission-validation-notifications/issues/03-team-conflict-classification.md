# 03: 重复、增员与结构性冲突识别

**What to build:** 新登记与既有预组队或队伍对比后，能区分完全一致、可识别的增员，以及换队长、替换或减少成员、跨队重叠、多队匹配等结构性冲突；冲突登记进入“需管理员确认”，且不会写入或覆盖队伍。

**Blocked by:** 01: 组队收集表提交与基础校验闭环.

**Status:** ready-for-agent

- [ ] 对完全一致、仅新增成员、换队长、成员替换、成员减少、跨队重叠和多队匹配分别给出可验证的分类结果。
- [ ] 任何结构性冲突均进入“需管理员确认”，不创建新队伍、不更新原队伍、不删除原成员。
- [ ] 已完成、已跳过或待确认的登记不被普通扫描重复判断、重复写入或重复通知。
