# 组队收集表：队伍人数与队友信息

`scripts/configure_team_form.py` 可通过飞书多维表格 API 完成以下静态配置：

- 显示必填的“队伍人数”单选字段（1–4）；
- 显示必填的队长姓名、手机号和邮箱；
- 显示“队友信息（可选）”多行输入，要求填写的有效行数与“队伍人数”一致；
- 隐藏旧的结构化队友字段，避免将静态隐藏误称为条件联动。

导入流程会拒绝人数不是 0–4、实际队友行数不等于声明人数，或队伍总人数不在 3–5 的提交。

## 可选的飞书界面条件显示

当前使用的表单字段 API 只能配置字段的静态可见性和必填性，不能由脚本验证或设置按数值显示字段的规则。若希望改用结构化队友字段，请在飞书多维表格的表单编辑界面手动完成：

1. 打开“组队收集表”的目标表单并进入编辑模式。
2. 显示“队伍人数”和第 1–4 组队友姓名、手机号、邮箱字段。
3. 为第 `n` 组队友字段设置条件：仅当“队伍人数”大于或等于 `n` 时显示，`n` 分别为 1–4。
4. 保存后分别用队伍人数 1、2、3、4 打开预览，确认只显示对应数量的队友组。
5. 分别提交一个人数相符和一个人数不符的测试记录；后者应在导入结果中被拒绝。

完成此界面配置后，删除或隐藏“队友信息（可选）”文本框，避免与结构化字段同时填写。导入流程会拒绝两种填写方式同时存在的提交。
